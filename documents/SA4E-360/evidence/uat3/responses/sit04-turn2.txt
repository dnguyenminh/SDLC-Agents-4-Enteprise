📋 Mô tả tổng quan
/**
 * Memory Module — handles mem_* tool operations.
 * Builder pattern: initialize() delegates to MemoryModuleBuilder.
 * DIP: core dependencies injectable via MemoryModuleDeps.
 * SRP: LLM initialization delegated to LLMInitializer.
 */Copy
4 pattern được áp dụng:
PatternÁp dụng ở đâuBuilderinitialize() → MemoryModuleBuilder (DB → Engine → Dispatcher → Promotion → Consolidation → BackgroundLLM)DIPMemoryModuleDeps interface — deps optional, production dùng default factory, test inject mockSRPLLM init được delegate ra LLMInitializer, không nằm trong class chính
