```typescript
private buildCompactableSession(maxTokens: number, usageFraction: number, messages: any[]): CompactableSession {
  return {
    modelId: "default", // Fixed TDD-02
    contextWindow: maxTokens,
    usage: usageFraction,
    messages: messages.map((m: any) => ({
      role: m.role || "user",
      content: typeof m.content === "string" ? m.content : JSON.stringify(m.content),
      toolName: m.toolName,
    })),
  };
}
```

#### Insertion Point 3: Helper `applyCompactionAndRecount` (<= 20 lines)
```typescript
private applyCompactionAndRecount(tabId: string, maxTokens: number, usageFraction: number, messages: any[]): void {
  const session = this.buildCompactableSession(maxTokens, usageFraction, messages);
  const result = this.sessionCompactor.compact(session);
  
  if (result.action === "compact" && result.session.messages.length > 0) {
    if (typeof (this.engine as any).setChatHistory === "function") {
      (this.engine as any).setChatHistory(result.session.messages);
    }
    this.contextUsageTracker.updateFromMessages(tabId, 
      result.session.messages.map((m: any) => ({ content: m.content || "" }))
    );
  }
}
```

## 3. Error Handling

- **Non-Fatal Compaction**: All compaction steps occur inside the existing `try/catch` block of `updateContextUsageAfterTurn`.
- If an error is thrown, it is caught and logged via `debugLog` without crashing the extension or blocking the chat.
- Guard checks (e.g., `typeof engine.setChatHistory === "function"`) prevent crashes if underlying engine features are absent.

## 4. Security Design

*Note: Security requirements SEC-330-01 and SEC-330-02 are inherited from SA4E-330 §Security.*

1. **SEC-330-01 (Role Elevation Prevention)**: 
   - The summary message generated by compaction must strictly use the `'user'` role.
   - It must include the `[compaction]` prefix.
   - Raw text must never be injected as the `'system'` role, preventing prompt injection attacks.
   - **Reference**: this control is implemented in `formatSummaryMessage` (`extension/src/pi-agent/summarizer.ts:58`, role hardcoded to `'user'` at `summarizer.ts:63`), invoked by `SessionCompactor.compact()` via `session-compactor.ts:120`. Verified sound by security-agent.
2. **SEC-330-02 (Usage Scale Contract)**: 
   - Usage input (percentage or token ratio) MUST be normalized to a fraction within the `[0, 1]` range via `normalizeUsageToFraction`.
   - Values exceeding `1.0` on the percentage scale are rejected or properly clamped, preventing overflow logic errors in trigger thresholds.
